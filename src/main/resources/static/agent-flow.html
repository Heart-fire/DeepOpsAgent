阶段 1 · Supervisor 编排循环（LLM 路由）
Supervisor：下一步调谁？ SUPERVISOR · qwen3.7-max
LLM 驱动的路由 Agent（非 if-else 编排器）。系统提示词约定三选一：调 planner_agent 出/调整计划 · 调 executor_agent 执行 · FINISH 输出报告。路由依据 = Planner 最近决策 + Executor 最近反馈
路由决策也消耗 LLM → 共用强模型
Planner：生成/调整诊断计划 PLANNER · qwen3.7-max
读 {input} + {executor_feedback}，输出 decision=PLAN|EXECUTE|FINISH 的 JSON。决策协议只有 30 行提示词——职责单一所以遵循度高
decision=PLAN（点击看输出示例）

阶段 2 · 收敛与输出
Planner 终局判断 PLANNER
三分支：证据链完整 → decision=FINISH（输出 Markdown 报告）｜证据不足/冲突 → Replan ｜预算耗尽信号 → 被迫 FINISH（报告如实标注未完成项）
《告警分析报告》固定模板输出 PLANNER → FINISH
活跃告警清单（表格）→ 告警根因分析 N（告警详情/症状/日志证据/根因结论）→ 处理方案执行 N → 结论（整体评估/关键发现/后续建议/风险评估）。所有结论必须引用工具真实返回，严禁编造
收尾：Trace 汇总 + SSE 推送 SYSTEM
